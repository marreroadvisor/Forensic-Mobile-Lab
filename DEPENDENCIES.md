# Dependencias incluidas en la descarga 3.2

El código propio tiene licencia MIT. Cada dependencia conserva su licencia y sus avisos; la licencia MIT del proyecto no sustituye esas condiciones.

Python 3.12 y Python 3.9: avisos PSF y componentes en `licenses/`. ADB: avisos de Android/AOSP en `licenses/ADB-NOTICE.txt`. Los runtimes completos conservan sus avisos en la app.
